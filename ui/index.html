        Set up a Fire TV for testing
        1. Settings → My Fire TV → About, then select the device name 7 times until it says you're a developer.
        2. Settings → My Fire TV → Developer options → ADB debugging: On.
        3. Scan Wi-Fi here (or type the TV's IP), then pick Allow on the TV's “Allow USB debugging?” prompt. Tick “Always allow”.

        Android TV / Google TV: Settings → System → About → press Build 7 times, then Developer options → USB debugging (and Wireless debugging on Android 11+).
