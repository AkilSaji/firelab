cd firelab && npm install && npm run build && npm link

# no TV? the engine on a simulated game
npm run demo

# your Fire TV: Developer options → ADB debugging
firelab devices --scan --connect
firelab doctor
firelab ui
firelab explore --package com.example.game

05 / 05 · FAQ

Questions

What is FireLab?

An open-source toolkit for testing apps and games on Fire TV and Android TV: a game-testing engine, a live dashboard, a CLI, an MCP server for AI agents, a performance library, every-model checks and Fire-TV-shaped emulators.

Do I need a Fire TV?

No. npm run demo runs the engine on a simulated game, firelab lab makes emulators shaped like real sticks, and web games can be tested in headless Chrome. A real stick gives the real numbers.

Which apps does it work with?

Native APKs get crash, ANR, exit, black-screen, frozen-picture and focus checks. Web apps in a debuggable WebView also get JavaScript errors, render-loop checks and focus from the page.

How accurate are the every-model verdicts?

They're estimates from one device plus model profiles. Two profiles are measured on real hardware; the rest come from published specs and are marked as estimates. Test on the real device before you ship.

Does it support Vega OS?

There is a Vega driver built from Amazon's documentation. It hasn't been run on a real Vega device yet.

Is it free?

Yes. MIT licensed, runs locally, no account and no telemetry.
